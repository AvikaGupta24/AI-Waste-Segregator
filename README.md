# AI-Waste-Segregator
A computer vision and machine learning-based waste classification project developed to explore how artificial intelligence can support more efficient and sustainable waste segregation.  The project combines image recognition, machine learning and hardware prototyping to investigate automated waste identification.

Project Objectives
- Explore ML-assisted waste identification and segregation.
- Train and test an image classification model using examples of common waste objects.
- Investigate how computer vision can reduce reliance on manual waste sorting.
- Develop a foundation for integrating AI/ML predictions with physical hardware.

Waste Categories
The project explores classification across six waste material categories:
- Organic waste
- Plastic
- Glass
- Metal
- Cardboard
- Electronic waste
- Technologies

Python: Computer vision and application logic
Machine Learning: Image classification
Jupyter Notebook: Model development and experimentation
Arduino: Hardware and sensor prototyping
H5 Model: Saved machine learning model

Repository Components
src/ — Python application and utility scripts
training/ — Model development notebook
models/ — Trained model
hardware/ — Arduino sketches
